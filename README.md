# Trading Trainer

Eine responsive Trading-Lernsimulation ohne Echtgeld und ohne externe Abhängigkeiten.

## Starten

`index.html` direkt im Browser öffnen oder über einen beliebigen statischen Webserver ausliefern.

## Funktionen

- Lokale, simulierte Candlestick-Kursdaten; die Zukunft bleibt bis zur Entscheidung verborgen.
- Kaufen, Verkaufen oder Abwarten mit eigener Begründung und Risikoeinschätzung.
- Regelbasiertes Coach-Feedback, das Analyse und Risikobewusstsein neben dem Ergebnis bewertet.
- Punkte, Lernkarten, Kapital-Simulation und Verlauf.
- Fortschritt und Entscheidungen werden ausschließlich in `localStorage` des Browsers gespeichert.

Die Anwendung ist ausschließlich zu Bildungszwecken gedacht und keine Anlageberatung.
